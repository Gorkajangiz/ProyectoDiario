<h1 align="center">Proyecto Diario (Incompleto)</h1>

<p align="center">
Un servicio API REST al que poder subir y bajar entradas de diario desde la misma red a un servidor local
</p>

<hr/>

<h2>📌 Descripción del proyecto</h2>

<p>
Creado con la intención de mantener organizadas las tareas diarias y recordar que hiciste cada día, orientado a introducir tres entradas diarias y dividirlo en categorías
</p>

<p>
Aún en desarrollo, es necesario implementar nuevas funcionalidades
</p>

---

<h2>🛠️ Características principales</h2>

<ul>
  <li>API REST en servidor local</li>
  <li>CRUD básico para entradas de diario</li>
  <li>Sistema de usuarios para mantener control</li>
  <li>Login para filtrar</li>
</ul>

---

<h2>🚀 Tecnologías utilizadas</h2>

<ul>
  <li>Java</li>
  <li>API REST</li>
  <li>MySQL</li>
  <li>Servidores locales</li>
</ul>
